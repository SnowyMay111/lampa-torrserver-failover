# TorrServer Failover для Лампы

Плагин для [Lampa](https://github.com/yumata/lampa-source): если основная ссылка на TorrServer не отвечает, автоматически включается дополнительная. Когда основная снова заработает, плагин возвращается на неё.

Две ссылки в Лампе уже есть: **Настройки → TorrServer → «Основная ссылка» / «Дополнительная ссылка»**. Плагин добавляет к ним автоматическое переключение и ничего не дублирует.

## Установка

1. В Лампе откройте **Настройки → Расширения → Добавить плагин**.
2. Вставьте ссылку и нажмите OK:

   ```
   https://cdn.jsdelivr.net/gh/SnowyMay111/lampa-torrserver-failover@v1.0.0/torrserver_failover.js
   ```

3. Перезапустите Лампу.
4. В **Настройки → TorrServer** заполните обе ссылки, например `http://192.168.1.10:8090` и адрес второго сервера. Ссылка пишется с `http://` и портом, без слэша в конце.
5. В конце этого же экрана появятся два пункта:
   - **Автопереключение серверов** — включено по умолчанию;
   - **Статус серверов** — показывает, какая ссылка отвечает с вашего устройства и какая включена сейчас.

## Как работает

- Основная ссылка проверяется первой. Не отвечает — включается дополнительная, появляется уведомление.
- Сервер проверяется тем же запросом, что и в самой Лампе (`POST /settings`). Если в TorrServer включён логин и пароль, они подставляются и для дополнительной ссылки.
- Проверка идёт при запуске, раз в минуту, при возврате в приложение, а также при ошибке подключения к серверу и при ошибке загрузки «Моих торрентов».
- Пока играет плеер, ссылка не переключается. Возврат на основную ждёт, пока не закрыты окна.
- Если включено автопереключение, настройкой «Использовать ссылку» управляет плагин. Чтобы выбирать вручную, выключите «Автопереключение серверов».
- Нужны обе ссылки. Если вторая не задана, плагин ничего не делает.

## Ограничения

- Уже идущее воспроизведение на другой сервер не переносится.
- Не проверялось на Android с внешним клиентом TorrServer («Встроенный клиент» выключен): там торрент открывает системное приложение.
- Код написан на ES5, чтобы работать на старых телевизорах (Tizen, WebOS).
